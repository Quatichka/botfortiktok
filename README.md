# Бот-нарезчик в Shorts

Присылаешь ссылку (TikTok, YouTube, Instagram, VK — всё, что умеет yt-dlp) — бот скачивает видео,
режет на части по 60 секунд и присылает каждую в формате 1080×1920:
название сверху, видео по центру, «PART N» снизу.

## Запуск

1. Создай бота у @BotFather и получи токен.
2. Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN`.
3. Установи зависимости и запусти:

```
pip install -r requirements.txt
python bot.py
```

ffmpeg ставить не нужно — он берётся из пакета `imageio-ffmpeg` (или используется системный, если есть).

## В боте

- `ссылка` — бот предложит выбрать баннер рекламодателя или нарезать без баннера
- `ссылка | Моё название` — со своим названием
- `/length 45` — длина части в секундах (5–180)
- `/rates` — таблица расценок всех рекламодателей
- `/speed` — скорость видео от 1x до 3x (или кнопка «⚡ Скорость» в галерее)

## Реклама внутри ролика

Бот вырезает рекламные интеграции из исходного видео ещё до нарезки: для YouTube — по
разметке зрителей в SponsorBlock (оплаченная реклама и самопиар) и по главам, которые автор
назвал «Реклама», «Спонсор», «Интеграция». У TikTok и других сайтов такой разметки нет.

## Баннеры

После выбора рекламодателя бот показывает его расценки и условия, а баннер ставит по его
правилам: момент показа, размер и позиция. Баннеры со звуком ставят основное видео на паузу,
беззвучные идут поверх него.
Правила считаются для каждой части отдельно — каждая часть публикуется как свой ролик.

- `banners.py` — рекламодатели, правила вставки и расценки (из `advertisers_banners.xlsx`)
- `visuals.py` — картинки в боте: приветствие, галерея баннеров, макет вставки, таблица расценок
- `banners/*.mp4` — подготовленные баннеры с вырезанным фоном (цвет сверху, маска снизу)
- `tools/prepare_banners.py` — пересобрать баннеры из исходников:
  `python tools/prepare_banners.py "путь/к/Баннеры/banners"`

Ставки и правила у рекламодателей меняются — перед публикацией сверяйтесь с их каналами.

## Настройки (.env)

| Параметр | По умолчанию | |
|---|---|---|
| `SEGMENT_SECONDS` | 60 | длина части |
| `FONT_PATH` | Nunito ExtraBold (скачается сам) | любой .ttf с кириллицей |
| `TEXT_COLOR` / `BOX_COLOR` | фиолетовый / белый | цвета подписи и плашки |
| `PART_LABEL` | `PART {n}` | например `Часть {n}/{total}` |
| `VIDEO_FIT` | `crop` | `crop` — на всю ширину с обрезкой по бокам, `fit` — целиком |
| `MIRROR` | `0` | `1` — отзеркалить видео (надписи и баннеры не зеркалятся) |
| `SPEED` | `1.0` | скорость по умолчанию (1–3); пользователь меняет свою через `/speed` |
| `CONTRAST` / `SATURATION` | `1.04` / `1.03` | едва заметная правка цвета видео; `1` — без изменений |
| `CUT_ADS` | `1` | вырезать рекламу из самого ролика (YouTube: SponsorBlock и главы «Реклама»); `0` — выключить |

Ограничение Telegram Bot API — 50 МБ на файл; минута видео выходит примерно 15–25 МБ.

Проверка без Telegram: `python test_render.py <ссылка>` — части появятся в `test_out/`.
